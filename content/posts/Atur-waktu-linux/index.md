Bagaimana caa mengatur Date&Time di linux(CLI)? 
sebenernya sangat mudah tetapi karena kita sering mengaturnya di pengaturan jadi lupa
Saya sebenernya juga lupa makannya membuat post ini hehehe.
Langsung aja.

Cara cek waktu kita di terminal cukup mudah cukup ketik **date** nanti keluar `Date&time` seperti di bawah.
![https://i.postimg.cc/fbV9b4dx/date.png](priview)

Jadi untuk mengaturnya cukup ketikkan:

```shell
date --set 2024-08-05 
```

 Dan untuk jam nya.
```shell
date --set 19:30:0 
```
Dan untuk cek tinggal ketik **date**.
