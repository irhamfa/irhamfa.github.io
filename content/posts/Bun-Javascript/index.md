## Apa Itu Bun 
Bun adalah runtime baru untuk javascript seperti node dan deno.
Menurut website {{< newtabref  href="https://bun.sh?ref=irha.my.id" title="bun sh" >}}, Bun lebih cepat dari node dan deno.</br>

## install Bun
Buka terminal Linux atau yg pakai Windows bisa pakai WSL Kemudian copy text di bawah

```bash
curl https://bun.sh/install | bash
```
Jika sudah selesai instalasinya masukkan perintah **bun --version** jika berhasil di install maka akan muncul versi yg kita install.
