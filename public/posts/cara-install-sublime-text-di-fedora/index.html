Cara Install Sublime Text Di Fedora

#text editor #linux

Sublime Text adalah kode editor sumber lintas platform, dan cukup ringan bagi laptop kentang seperti punya saya 😢.

Begini cara install sublimetext di fedora dan ikuti langkah langkah berikut ini :

Install the GPG key

sudo rpm -v --import https://download.sublimetext.com/sublimehq-rpm-pub.gpg

Untuk versi Stable

sudo dnf config-manager --add-repo https://download.sublimetext.com/rpm/stable/x86_64/sublime-text.repo

Untuk versi Dev

sudo dnf config-manager --add-repo https://download.sublimetext.com/rpm/dev/x86_64/sublime-text.repo

Kemudian Install Sublime-text

sudo dnf install sublime-text

Jila kalian ingin meng-install sublime text ketikkan y dan tidak dengan n
Tunggu sampai proses selesai, dan ketika sudah selesai

Kemudian buka Sublime-text yg sudah anda install tadi
jika kalian ingin memasukkan lisensinya bisa ke menu help ⏩ insert lisensi


Dan masukkan lisensi anda, jika sudah selesai akan seperti ini

Dan Sublime-text siap di gunakan 😚.

Buat yg belum punya lisensi sublime-textnya bisa beli di official web sublime-text atau tidak memasukkan lisensi juga ga papa, sublime-text bisa digunakan tanpa harus memasukkan lisensinya.
